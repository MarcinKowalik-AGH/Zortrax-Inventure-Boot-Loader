# Inventure v1.5-HW2 — przykłady P4 / P4 examples

[Pełne przykłady po polsku](KONSOLA_P4_PRZYKLADY_PL.md) · [Complete English examples](P4_UART_EXAMPLES_EN.md) · [Indeks v1.5](README.md)

Trzy przypadki: oryginalny zaszyfrowany pakiet z SD, już odszyfrowana APP oraz własna APP/odpowiedni Klipper IVB. Publiczne skrypty nie odszyfrowują ZRTX i nie odtwarzają tail20. Konsola `INV>` nie jest konsolą instalatora `SD>` ani G-code.

Three cases: encrypted stock via SD, already-decoded stock APP and a compatible custom/Klipper IVB. Public tools contain no decryption or tail-generation secrets. The language-specific manuals contain the runnable commands.
